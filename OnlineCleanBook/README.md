# Online-Clean-Book
**Online Bookstore Website Project**

## 1. Project Overview

Clean Book is an online bookstore website designed to provide customers with a convenient platform to browse, search for, and purchase books online. The system supports guest shopping, customer accounts, member pricing, and administrator functions for managing books, categories, and customer orders.

## 2. Product Categories

- Textbooks
- Novels
- Self-help Books

## 3. Main Features

- User Registration and Login
- Browse and Search Books
- View Book Details
- Shopping Cart Management
- Guest Checkout and Order Placement
- Member Pricing
- Manage Books
- Manage Categories
- Manage Customer Orders
- Asynchronous User Interaction

## 4. Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** Laravel Herd / XAMPP
- **Version Control:** Git and GitHub
