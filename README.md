# Online-Clean-Book
Online Bookstore Website Project

## 1. Project Overview

Clean Book is an online bookstore website designed to provide customers with a convenient platform to search for, browse, and purchase books online.

## 2. Product Categories

- Textbooks
- Novels
- Self-help Books

## 3. Main Features

- User Registration and Login
- Browse and Search Books
- View Book Details
- Shopping Cart
- Place Orders
- Manage Books
- Manage Categories
- Manage Customer Orders

## 4. Proposed Technology Stack

- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
- Backend: PHP
- Database: MySQL
- Development Environment: XAMPP
- Version Control: Git and GitHub
