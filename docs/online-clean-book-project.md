I. PROJECT INFORMATION
1. Project Name
Clean Book is an e-commerce website project that focuses on selling
books online. The website aims to provide customers with a convenient
and easy-to-use platform where they can browse, search for, and purchase
books from different categories.
The project focuses on making the online book-buying process simpler by
providing clear product information, reasonable navigation, and an
organized shopping experience.

4. Problem Statement
4.1. Existing Problems
Buying books can sometimes be inconvenient for customers, especially
when they do not know exactly which book they want or where to find it.
Some common problems include: - Customers may spend a lot of time
searching for books that match their interests and needs. - Finding
books by title, author, or category may be difficult when product
information is not well organized. - Customers may not have enough
information about a book's content, price, and availability before
making a purchase. - Visiting physical bookstores may be inconvenient
for customers who live far away or have limited free time.
4.2. Proposed Solution
Clean Book aims to address these problems by developing an online
bookstore with a simple and user-friendly interface.
The website will allow customers to: - Browse books by category. -
Search for books by title or author. - View detailed information about
each book. - Add books to a shopping cart and update quantities. - Place
orders online. - View relevant product information before making a
purchase. - Enjoy a more convenient shopping experience through the
online store.
Through these features, Clean Book aims to reduce the time and effort
required to buy books, make books easier to access, and provide
customers with a more convenient online shopping experience.

2. User Flow
The Clean Book website is designed with a simple and user-friendly
interface. Its main purpose is to help customers find suitable books and
complete their purchases conveniently.
2.1. Customer User Flow
The customer shopping process consists of the following steps: 1. The
customer visits the Clean Book homepage. 2. The customer searches for
books or browses available book categories. 3. The customer selects a
book to view its detailed information. 4. The customer adds the selected
book to the shopping cart. 5. The customer reviews the shopping cart and
checks the selected books. 6. The customer logs in or proceeds with the
order process. 7. The customer completes the ordering process. 8. The
system confirms that the order has been placed successfully.
Customer User Flow Diagram:
``` mermaid
flowchart TD
    A[Home Page] --> B[Search / Browse Categories]
    B --> C[View Book Details]
    C --> D[Add to Cart]
    D --> E[Review Shopping Cart]
    E --> F[Login / Place Order]
    F --> G[Order Confirmed Successfully]
```
2.2. Administrator User Flow
The administrator uses the management interface to maintain website
information and process customer orders.
The administrator logs in to the system.
The administrator accesses the Admin Dashboard.
The administrator selects a management function, such as managing
books, authors, publishers, categories, or orders.
The administrator performs the required actions, such as adding,
editing, deleting, or viewing records.
The system saves the changes to the database and updates the
information displayed on the website.
Administrator User Flow:
``` text
Admin Login
    → Admin Dashboard
    → Select Management Function
    → Add / Edit / Delete / View Data
    → Save Changes to Database
    → Display Updated Information
```

3.1. System Architecture
The system is expected to follow a basic Client--Server
Architecture, consisting of three main components:
Frontend: Uses HTML, CSS, Bootstrap, and JavaScript to display
the website interface and handle user interactions.
Backend: Uses PHP to process user requests, implement business
logic, and communicate with the database.
Database: Uses MySQL to store and manage system information.
When a customer interacts with the website, the frontend sends requests
to the PHP backend. The backend processes these requests and retrieves
or updates the necessary information in the MySQL database before
returning the results to the frontend.

Tiki provides a multi-category shopping interface with various product
sections and promotional content. Its search and category features help
customers explore different products. However, the large amount of
information may require users to spend more time finding specific
products.

specialized product categories help customers find books more easily.

Based on the observations of Tiki and Fahasa, Online Clean Book will
focus on a simple and user-friendly interface. The website will provide
clear book categories, an easy-to-use search function, detailed book
information, and a straightforward shopping process.
